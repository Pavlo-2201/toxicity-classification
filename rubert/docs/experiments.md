## Сравнение моделей по протоколу

Протокол зафиксирован в `configs/protocol.json`. Полная серия из 18 обучений и двух
готовых классификаторов повторно выполнена на Python 3.13.12,
PyTorch 2.8.0+cu128, Transformers 4.57.6 и PEFT 0.17.1. Запуск был продолжен после
прерывания. Все 20 отчётов проверены на полноту в каталоге исходного запуска до публикации.

### Протокол

- Train разделён на fit и калибровочную часть (15 %, стратифицированно, seed 42).
- Эпоха выбирается по AP на validation, порог — по F1 на калибровочной части.
  Test не используется для выбора модели, эпохи или порога.
- Каждая конфигурация обучается с seed 42, 43 и 44; сравниваются также готовые
  классификаторы, которые видели данные задачи или ok.ru.
- Лучшая конфигурация выбирается по среднему AP на validation; среди эквивалентных
  учитываются CPU-время и AP на длинных текстах. Выбрана `base_L128`.
- Времена измерены на i5-11400H и RTX 3050 Ti Laptop 4 ГБ; CPU — прямой проход
  без токенизации. Время зависит от нагрузки системы.

### Итоговые артефакты

Полная серия не сохраняет веса. Для итоговых моделей выполнены отдельные прогоны
тех же конфигураций с seed 42 и сохранением выбранной эпохи. Отчёты этих прогонов:

- [`reports/final_runs/base_L128__s42.json`](../reports/final_runs/base_L128__s42.json)
  — ruBert-base; веса `models/rubert-toxic`;
- [`reports/final_runs/base_L128_lora__s42.json`](../reports/final_runs/base_L128_lora__s42.json)
  — LoRA-адаптер; веса `models/rubert-toxic-lora`.

В отчёте каждого финального прогона записаны SHA-256 весов, выбранная эпоха и порог.
При загрузке модель сверяется с соответствующим отчётом. Отчёты проверки токенизации,
предсказаний и CLI находятся в `reports/eval/`.

### Каталог запуска

```bash
cd rubert
python scripts/experiments.py --out experiments/runs/my-run
python scripts/check_experiment_run.py experiments/runs/my-run
python scripts/summarize_experiments.py --run-dir experiments/runs/my-run
# После прерывания:
python scripts/experiments.py --resume experiments/runs/my-run
```

Новый запуск создаёт свой пустой каталог и не использует готовые отчёты. При продолжении
сверяются протокол, данные, модели и код, а пропускаются только завершённые прогоны из
манифеста. Итоговые модели обучаются отдельно командами из корня проекта:

```bash
toxic train rubert
toxic train rubert --config rubert/configs/final_lora.json
```

Существующие результаты защищены от перезаписи; для нового места используйте
`--output-dir` и `--run-report`. Повторное обучение на GPU побитно не гарантируется.
